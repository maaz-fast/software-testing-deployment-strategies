# NexaCare Solutions Final Project

This directory contains the Final Project submission for the Software Testing, Deployment, and Maintenance Strategies course.

## Files Included:

1. **`NexaCare_Final_Project.md`**
   * The complete Testing and Release Planning Kit in Markdown format.
   * Includes all 8 required sections structured clearly.

2. **`NexaCare_Final_Project.docx`**
   * The same Testing and Release Planning Kit, converted into a Microsoft Word Document for easy submission or viewing offline.


## Project Details
The documents address the scenario of NexaCare Solutions launching version 3.0 of their web-based appointment scheduling platform. It covers:
- Test strategies and traceability matrices.
- Deployment checklists and rollback plans.
- Data migration plans for 1.2 million patient records.
- Post-deployment monitoring and non-functional requirements (Golden Signals) to handle 3-5x traffic spikes on Monday mornings.
